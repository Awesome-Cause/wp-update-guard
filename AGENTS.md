# Agent instructions

## Task tracking

- Issues for this repo live in GitHub Issues here and on the [Awesome Cause](https://github.com/orgs/Awesome-Cause/projects/1) project board.
- Work that isn't code goes in Awesome-Cause/ops on the [Sales & Marketing](https://github.com/orgs/Awesome-Cause/projects/8) project.
- Fields are Status (Backlog, Todo, In Progress, Waiting on Daniel, Done), Lane (Engineering, Marketing, Sales, Content, Founder, Ops) and Priority (Urgent, High, Medium, Low). Use "Waiting on Daniel" when only Daniel can unblock an item.
- Link PRs with `Fixes #N`.
- To find an old `AWE-NN` reference, search the org's issues for `AWE-NN`.
- Do not create or update Linear issues.
